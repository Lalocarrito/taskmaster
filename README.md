# taskmaster — Gestor de proyectos y tareas

**Creador:** Josué Martínez — [@Lalocarrito](https://github.com/Lalocarrito)

Web hecha con Flask y SQLite para administrar proyectos y tareas: CRUD completo, estados de
tarea (pendiente, en progreso, completada) y una API REST que consume el frontend.

## Requisitos y ejecución

- Python 3
- Flask

```bash
pip install flask
python app.py
```

Abre http://localhost:5000. La base de datos se crea sola en el primer arranque.
